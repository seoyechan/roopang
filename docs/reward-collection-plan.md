# 월급루팡 보상·수집함 기획

## 핵심 경험

**오늘은 커피 한 잔, 언젠가는 자동차 한 대.**

숫자가 목표 금액을 넘으면 커피나 짜장면 그림이 위에서 툭 내려온다. 그림은 수집함에 들어가고 개수가 늘어난다. 매일 모으는 작은 보상과 오랫동안 쌓는 큰 목표를 함께 보여준다.

커피 5,000원과 짜장면 10,000원은 사용자 요청값이다. 나머지 품목·금액은 기획 제안이며 실제 판매 가격을 의미하지 않는다.

## 1. 전체 보상 단계

전체 누적액 기준으로 아래 단계를 순서대로 해금한다. ‘다음 목표’는 아직 달성하지 않은 가장 가까운 단계로 자동 변경한다.

| 금액 | 물건 | 달성 문구 | 매일 수집도 가능 |
| --- | --- | --- | --- |
| 5,000원 | 커피 | 커피 한 잔 확보! | 오늘 5천 원 달성 시 1잔 |
| 10,000원 | 짜장면 | 오늘 점심은 짜장면! | 오늘 1만 원 달성 시 1그릇 |
| 20,000원 | 치킨 | 퇴근 후 치킨 각! | 오늘 2만 원 달성 시 1마리 |
| 50,000원 | 외식 | 오늘 저녁은 내가 쏜다! | 오늘 5만 원 달성 시 1회 |
| 100,000원 | 쇼핑백 | 쇼핑백 하나 챙겼다! | 누적 목표만 |
| 200,000원 | 운동화 | 루팡해서 새 신발! | 누적 목표만 |
| 500,000원 | 헤드폰 | 이제 잡음은 안 들려요. | 누적 목표만 |
| 1,000,000원 | 여행 가방 | 월급은 흐르고, 나는 떠나고. | 누적 목표만 |
| 3,000,000원 | 노트북 | 쉬어서 장비 바꿨다! | 누적 목표만 |
| 10,000,000원 | 자동차 열쇠 | 드림카가 가까워졌다! | 누적 목표만 |
| 30,000,000원 | 자동차 | 드디어 내 차 한 대! | 누적 목표만 |

- 전체 누적 목표는 각 단계 한 번만 해금된다. 3천만 원 이후에는 ‘자동차 달성’ 상태로 전체 금액을 계속 표시한다.
- 오늘 보상은 자정에 새로 시작하며, 하루에 종류별 한 번씩 수집한다.
- 오늘 1만 원을 달성하면 커피 1잔과 짜장면 1그릇을 수집한다. 커피 2잔으로 계산하지 않는다.
- 다음 날 5천 원을 달성하면 커피 1잔을 추가한다. 수집함 커피 개수는 2잔이 된다.
- 누적 목표에서 커피를 해금해도 일일 수집함에 1잔을 별도로 더하지 않는다. 누적 해금은 배지 컬렉션이다.
- 같은 순간 일일/누적에서 동일한 물건을 달성하면 낙하 연출 한 번으로 합치고 ‘첫 누적 목표도 달성’이라는 보조 문구를 붙인다.
- 금액을 차감하지 않는다. 같은 기록이 여러 단계 달성에 사용되는 기념 보상 구조이다.

## 2. 화면 구성

### 타이머 아래: 오늘의 다음 보상

- 0~4,999원: 작은 컵 그림 + ‘커피 한 잔까지 1,250원’처럼 남은 금액.
- 5천 원 달성: 커피 낙하 → ‘커피 한 잔 확보!’ → ‘다음은 짜장면 · 5,000원 남음’.
- 1만 원 달성: 짜장면 낙하 → ‘짜장면 한 그릇 확보!’ → 다음 목표 치킨으로 교체.
- 5만 원 이후: ‘오늘의 보상 모두 수집!’ 표시. 타이머는 계속 진행.
- 오늘 누적과 이번 회차 금액은 라벨로 구분한다. 회차 종료/재시작으로 오늘 진행이 초기화되지 않는다.

### 수집함: 지금까지 모은 것들

제목 ‘루팡 수집함’, 보조 문구 ‘쉬는 시간이 이만큼 쌓였어요’.

- **매일 모은 보상:** 컵 그림 여러 개 + ‘커피 12잔’, 그릇 그림 + ‘짜장면 7그릇’, 치킨 그림 + ‘치킨 3마리’.
- 각 종류의 그림은 최대 5개만 펼쳐 보이고, 실제 총개수는 숫자로 표시한다. 1,000잔을 모아도 이미지 1,000개를 만들지 않는다.
- PC에서는 진열 선반 같은 한 줄 구성, 모바일에서는 2열. 0개인 종류는 회색 윤곽과 ‘아직 0잔’.
- 누르면 해당 종류를 모은 날짜 목록을 연다. 구매 내역으로 보이지 않게 ‘달성 기록’이라고 표시.
- **누적 컬렉션:** 해금한 물건을 컬러, 미달성 물건은 윤곽으로 표시한다. 자동차는 잠겨 있어도 작은 실루엣으로 최종 목표를 보여준다.
- 처음에는 대표 일일 보상과 다음 누적 목표만 노출. 11단계 전체 컬렉션은 ‘전체 목표’에서 펼친다.

### 전체 누적 목표

‘누적 루팡 284,500원’ → 운동화 달성 표시 → ‘다음은 헤드폰 · 215,500원 남음’.

자동차는 별도의 작은 종착점 안내 ‘최종 목표 · 자동차 30,000,000원’으로 보여준다. 먼 자동차 목표만 메인에 크게 띄우지 않고 가까운 목표부터 바꾼다.

## 3. 물건이 내려오는 애니메이션

### 공통 동작: 총 1.2~1.6초

| 구간 | 화면 동작 |
| --- | --- |
| 0~120ms | 달성 숫자의 강조색이 잠깐 바뀌고 짧은 달성 문구 등장 |
| 120~650ms | 타이머 아래 보상 영역 상단에서 해당 그림 1개가 100~160px 낙하. 살짝 회전 |
| 650~900ms | 바닥에서 한 번만 8~12px 튕김. 가벼운 squash/stretch |
| 900~1,350ms | 그림이 작아지며 수집함 해당 칸으로 이동. 칸이 한 번 강조되고 수량 +1 |
| 이후 | 달성 문구를 잠시 유지한 뒤 다음 목표와 남은 금액 표시 |

- 버튼·입력란을 가리지 않는 전용 보상 영역을 사용한다. 레이어는 pointer-events: none.
- 모바일에서 수집함이 화면 밖이면 보상 영역에서 축소하며 사라지고 ‘수집함에 담았어요’ 표시. 강제 스크롤하지 않는다.
- 데이터 획득은 목표 판정 시 즉시 확정한다. 애니메이션 완료 여부로 저장을 결정하지 않는다.
- 화면은 미리 확보된 공간에서 transform/opacity로 움직여 레이아웃이 밀리지 않게 한다.

### 물건별 특징

- 커피: 초록 테이크아웃 컵이 내려오고 작은 김이 한 번 피어오름.
- 짜장면: 검은 면과 초록 포인트 그릇이 내려오고 젓가락이 살짝 흔들림.
- 치킨: 작은 포장 상자가 내려오고 뚜껑이 한 번 들썩임.
- 쇼핑·운동화·헤드폰·여행: 같은 낙하 규칙을 쓰되 해당 그림만 변경.
- 자동차: 작은 자동차가 위에서 내려와 서스펜션처럼 한 번 눌렸다가 복원. 이어 바퀴가 짧게 굴러 컬렉션에 안착. 최대 2초.
- 비슷한 순간에 여러 목표를 넘으면 최대 3개만 순차 연출하고 나머지는 ‘보상 N개를 모았어요’로 묶는다. 모든 획득 기록은 반영한다.
- 백그라운드에서는 애니메이션을 실행하지 않는다. 복귀 시 미확인 달성을 요약하고 대표 물건 1개만 연출한다.
- 모션 줄이기 설정에서는 낙하·회전·튕김·이동을 생략한다. 텍스트와 수량만 변경하고 소리는 사용하지 않는다.

## 4. 그림 제작 기준

- 기존 괴도 캐릭터와 같은 굵기의 검은 선, 밝은 바탕, 초록 포인트.
- 커피·짜장면·치킨 등 물건마다 투명 배경의 독립 이미지. 낙하와 수집함에서 같은 원본 사용.
- 보상 영역에서는 80~112px, 수집함에서는 40~64px. 작은 크기에서도 알아볼 수 있는 단순한 형태.
- 실사 상품 이미지나 실제 브랜드 로고는 사용하지 않는다.
- 각 이미지에 한국어 대체 텍스트 제공. 장식용 중복 그림은 보조기술에서 숨긴다.
- 시안은 정적 이미지로 낙하 순간을 표현한다. 실제 동작은 구현 후 별도 검증한다.

## 5. 획득 계산과 저장

```text
오늘 커피 획득 = 오늘 환산 금액 >= 5,000
전체 커피 수량 = 환산 금액이 5,000 이상인 날짜 수
전체 짜장면 수량 = 환산 금액이 10,000 이상인 날짜 수
누적 운동화 해금 = 전체 환산 금액 >= 200,000
다음 누적 목표 = 전체 환산 금액보다 큰 첫 번째 기준값
```

- 일일 획득 키: `daily:2026-09-30:coffee`.
- 누적 해금 키: `lifetime:sneakers`.
- 획득 상태와 수량은 원본 회차에서 계산하며, 저장된 합계나 화면 반올림값으로 판정하지 않는다.
- 축하 효과 재생 여부만 고유 키로 저장한다. 새로고침과 중복 탭으로 효과를 반복하거나 개수를 늘리지 않는다.
- 날짜가 넘어가는 회차는 한국 시간 자정으로 나눈 뒤 각 날짜에 대해 획득 여부를 계산한다.
- 회차 삭제 시 합계·수집 수량·누적 해금을 재계산한다. 삭제 확인창에 ‘이 기록으로 모은 보상도 다시 계산돼요’ 표시.
- 기록 삭제 후 같은 목표를 재달성해도 이미 재생한 동일 키의 축하 효과는 반복하지 않는다. 달성 상태와 수량은 정상 복구한다.
- 향후 목표 금액을 바꾸는 경우 보상표 버전별로 과거 날짜의 기준을 유지하도록 데이터 이전이 필요하다. 첫 출시 전에는 제안값 조정 가능.

## 6. 검증 예시

| 상황 | 기대 결과 |
| --- | --- |
| 오늘 4,999.99원 → 5,000원 | 커피 1잔 획득, 다음 일일 목표 짜장면 |
| 오늘 5,000원 → 10,000원 | 커피 1잔 유지, 짜장면 1그릇 획득 |
| 다음 날 5,000원 달성 | 커피 누적 2잔, 짜장면 누적 1그릇 |
| 처음 사용한 날 10,000원 달성 | 일일 2종 수집, 누적 2단계 해금. 일일 수량 중복 가산 없음 |
| 전체 199,999원 → 200,000원 | 운동화 1회 해금, 다음 누적 목표 헤드폰 |
| 새로고침·다중 탭 | 수집 수량 유지, 같은 획득 중복 없음 |
| 자정 넘김 | 일일 금액/목표 재시작, 수집함과 누적 목표 유지 |
| 전체 1,000,000원 달성 | 여행 해금, 다음 목표 3,000,000원 노트북 |
| 전체 30,000,000원 달성 | 자동차 해금, 이후 금액은 계속 누적 |
